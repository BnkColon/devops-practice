# devops-practice
Build with Infrastructure as Code, a simple Nginx application with all the free tools. 

Given that Linux, Docker, Kubernetes, Git and Github, Github Actions, Python, AWS (have free tiers), Terraform, ArgoCD and Flux, Prometheus and Grafana are free. 

Goal: build and deploy an Nginx App with Helm. 
How: We’ll provision an EKS cluster with Terraform and a tiny NGINX app deployed via Helm (with ConfigMap + Secret).
